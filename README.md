# 🐊 Gator RSS — A Minimalist RSS Aggregator in Go

Gator is a command-line RSS reader and feed aggregator written in Go. It lets you:

- register users
- add RSS feeds
- follow feeds
- periodically fetch posts
- browse your personalized feed

All data is stored in PostgreSQL, and the project uses `sqlc` for type-safe database access.

---

## 🚀 Features

- **User accounts** — each user has their own followed feeds and personalized post list.
- **Feed management** — add new RSS feeds, list them, and follow/unfollow as needed.
- **Automatic following** — when you add a feed, you automatically follow it.
- **Aggregator** — a background loop fetches posts from all feeds at a configurable interval.
- **Browsing** — view your aggregated posts in a clean table format.
- **Type-safe SQL** — all queries are generated by `sqlc` for safety and maintainability.

## 🛠️ Installation

### Prerequisites
- Go 1.22+
- PostgreSQL 14+
- `sqlc` installed  
  ```
  go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
  ```

### Clone the repo
```
git clone https://github.com/Screentime42/gator-rss-go
cd gator-rss-go
```

### Configure environment
Create a `.env` file:
```
DB_URL=postgres://postgres:password@localhost:5432/gator?sslmode=disable
```

### Run migrations
```
go run . reset
```

## 🧑‍💻 Usage

All commands follow this pattern:
```
go run . <command> [args...]
```

### Register a user
```
go run . register <username>
```

### Log in
```
go run . login <username>
```

### Add a feed (Personally added feeds are followed upon Add)
```
go run . addfeed "Example Feed" https://example.com/rss
```

### Follow a feed manually
```
go run . follow https://example.com/rss
```

### List all feeds
```
go run . feeds
```

### List who you follow
```
go run . following
```

### Run the aggregator
```
go run . agg 30s
```

### Browse posts
```
go run . browse
```

## 🧩 How It Works

### Database
The schema includes:
- `users`
- `feeds`
- `feed_follows`
- `posts`

Each feed belongs to a user (the creator).  
Each user can follow many feeds.  
Posts are linked to feeds.

### Aggregator
The aggregator:
1. selects the next feed to fetch  
2. downloads the RSS/Atom XML  
3. parses items  
4. inserts new posts  
5. updates `last_fetched_at`

### SQLC
All SQL lives in `sql/queries/`.  
Run:
```
sqlc generate
```
